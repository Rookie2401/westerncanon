# Western Canon — offline reader for classical texts

Mobile-first PWA (React + TypeScript + Vite) for reading classical philosophical
and theological texts fully offline. All text is bundled under `data/`; **the
app never fetches anything at runtime**.

The model is **Author → Work → (recursive) Division → Passage**. Each Work
declares a `profile`:

- `summa` — the rich Objectiones / Sed contra / Respondeo / Responsiones reader.
- `generic` — a spare division-heading + passage reader, typographically
  matched to the Latin side.

The home screen is the **Library**: authors in chronological order (by birth /
floruit, so Aristotle would slot in first when added), each a collapsible row
of their works. Then Author → Work → the reader. Bookmarks, Continue Reading,
last-position and search work across the whole library; per-work "About the
text" pages carry the edition, provenance and licensing for each text.

## Run it

```
npm install
npm run dev
```

Then open the printed `http://localhost:5173/` URL. For an offline / installable
(PWA) check: `npm run build && npm run preview`, load the page once, then it works
with the network disconnected.

## Isagoge data (`data/isagoge-grc/`, `data/isagoge-la/`)

Two independent Works (not a parallel-language toggle). Generated by
`scripts/import-isagoge-grc/` and `scripts/import-isagoge-la/` from raw sources
committed under each `scripts/import-isagoge-*/raw/` (First1KGreek TEI; a
Latin Wikisource wikitext dump). `scripts/import-isagoge-shared/` holds the
27-entry section table (a preface + sections I–XXVI, identical ids in both
works), the prose "About the text" bodies, and the cross-validator.

- `work.json` — the `GenericWork`: `divisions[]`, each with a verbatim
  `sourceHeading`, an **editorial** English `editorialTitle` (marked "ed." in
  the UI, never presented as source text), and `passages[]`.
- `about.json` — `WorkAbout`: edition / editor / translator / provenance /
  licence plus the prose section bodies rendered at `/work/:id/about`.
- `anomalies.json`, `VALIDATION_REPORT.md` — generated; every preserved source
  irregularity is listed (e.g. the misprinted section-XII heading in the Greek,
  the `<quod>` editorial supplement in the Latin). Nothing is silently
  corrected. The Greek keeps **Busse pagination** as the canonical reference
  (page level — the digital source's line markers proved unreliable); the Latin
  has no Busse numbers and cites by section + paragraph.

Aristotle's *Categories* and *De Interpretatione* follow the same pattern, each
in two independent Works: Greek importers under
`scripts/import-aristotle-categoriae-grc/` and `scripts/import-aristotle-deint-grc/`
(raw First1KGreek TEI committed under each), and Latin importers under
`scripts/import-aristotle-categoriae-la/` and `scripts/import-aristotle-deint-la/`
(raw Latin Wikisource `action=parse` dump committed under each). A shared
`scripts/import-aristotle-shared/` holds the 15- / 14-entry chapter tables
(identical ids across each grc/la pair), the Latin-Wikisource parser, the About
prose, and the four-work validator; output lands under `data/categoriae-grc/`,
`data/categoriae-la/`, `data/de-interpretatione-grc/`,
`data/de-interpretatione-la/`. Neither the Greek TEI nor the Latin Wikisource
source carries Bekker page/line numbers, so all four works are cited by chapter
(plus an editorial English chapter title marked "ed."; the Latin also keeps the
verbatim Latin rubric — e.g. "DE SUBSTANTIA" — where the source prints one).
The Latin is verbatim: consonantal *u* is not changed to *v*, editorial
angle-bracket supplements (`<'ferus'>`) and lacuna marks (`<...>`) are kept and
flagged, and the two U+FFFD line-wrap artefacts in the Latin *Categoriae* ch. 10
are the only characters repaired.

## Euclid data (`data/euclid-elements/`)

Generated by `scripts/import-euclid/` from a single bundled TEI file,
`scripts/import-euclid/raw/tlg1799.tlg001.perseus-grc2.xml` (Perseus Digital
Library / OpenGreekAndLatin canonical-greekLit, digitising J. L. Heiberg's
*Euclidis Opera Omnia*, Leipzig: Teubner 1883–88 — the standard critical
edition, public domain). `scripts/import-euclid-shared/` holds the ground-truth
structure table, the About prose, and the validator.

The source nests exactly three levels: Book (I–XIII) → section-type group
(Definitions / Postulates / Common Notions / Propositions — editorial English
group labels; Book X alone repeats the Definitions/Propositions pair three
times, its proposition numbering continuing 1–47, 48–84, 85–115 rather than
restarting) → a single numbered definition/postulate/common notion/proposition,
each one reader Division. 13 books, 607 leaf divisions, matching an
independently-researched structural count of the edition exactly.

- Four numbering gaps (Book I has no prop. 30; Book II no prop. 7; Book X's
  first proposition-group no prop. 6; Book XII no prop. 7) are genuine,
  long-documented features of Heiberg's edition, not importer errors.
- 507 `<del>` spans (text Heiberg marks inauthentic — mostly corollaries and
  interpolated lemmas) are excluded from the reading text and logged
  individually in `anomalies.json`; five leaf divisions end up with zero
  surviving passages as a result. 4 `<add>` editorial insertions are kept and
  logged.
- 498 `<figure/>` diagram markers all point to a dead host (heml.mta.ca) with
  no recoverable image; each is preserved as an honest "diagram not yet
  available in this build" note with an exact citation (e.g. "Heiberg,
  *Elements* I.47") — never a fabricated or reconstructed image.
- Every definition/postulate/common-notion/proposition is labelled by its
  printed number only; only Book titles and section-type group labels carry
  editorial (marked "ed.") framing, given the technical mathematical content.

## Archimedes data (`data/archimedes-*/`)

Generated by `scripts/import-archimedes/` from 13 bundled TEI files under
`scripts/import-archimedes/raw/` (OpenGreekAndLatin/First1KGreek,
`tlg0552.tlg001`–`tlg013`). `scripts/import-archimedes-shared/` holds the
ground-truth work table, the TEI walker/converter, the About prose, and the
cross-work validator.

**Correction to an initial assumption:** the edition these TEI files actually
digitise is **Charles Mugler's** *Archimède* (Les Belles Lettres, "Budé", 4
vols., 1970–72) — verified from the transcription's own bibliographic
metadata and page markers — **not Heiberg**, as originally assumed before the
files were inspected. Mugler's proposition numbering follows Heiberg's
traditional scheme (so citations like "Method, prop. 14" still mean what
every modern edition means by them), but the *page* references bundled here
(e.g. "Mugler vol. 3 p. 82") are Mugler's own pagination, not Heiberg's; the
two are never conflated.

13 genuinely distinct works (not editions of one text, so none are grouped in
the Library): three multi-Book works (*On the Sphere and Cylinder*, *On the
Equilibrium of Planes*, *On Floating Bodies* — Books rendered as closed-by-
default containers with no invented title beyond their number) and ten
flat works. Every leaf division is labelled by its printed number only —
across ~250 sections of highly technical geometric/mechanical content this
importer deliberately does not invent an English gloss per proposition, to
avoid asserting unverified scholarly claims; `editorialTitle` is `null`
throughout.

- References are Mugler volume/page (`pb`-derived, verified monotonically
  increasing per file); *Fragments* instead cites each testimony's secondary
  source (Pappus, Theon, etc. — Archimedes' words there survive only as later
  quotations), with the Mugler span kept at the division level.
- Corpus-wide transcription hygiene: NFC normalisation of a handful of
  Greek-Extended/ano-teleia code points per file, and decoding of the
  `&#9651;` numeric entity to the real triangle glyph ▵ (U+25B3) — both
  logged with per-file counts in each `about.json`.
- `<del>` (editorial deletion), `<gap reason="omitted">` (a true manuscript
  lacuna — no filler text is ever inserted) and `<add cause="omitted">` (an
  editor's conjectural restoration, kept in the reading text unlike a gap) are
  each excluded/flagged/kept per that same convention and logged individually
  in `anomalies.json`.
- *The Method* survives only via the Archimedes Palimpsest and is by far the
  most heavily marked-up file (233 gaps, 225 restorations) as a result — every
  one preserved exactly as the edition prints it.
- *Stomachion* preserves only the work's opening — fragmentary in the
  tradition itself, not from any importer omission.
- Diagram `<figure>` markers (same dead heml.mta.ca host as Euclid) are
  preserved as honest notes with an exact Mugler citation, never a fabricated
  image.

## Summa data (`data/summa/`)

Generated by `scripts/import-summa/` from a single bundled source file,
`scripts/import-summa/raw/xml_latin_nl.xml` (committed; the Dutch translation in
it is stripped during import). Re-download command if it is ever removed is in
`.gitignore`.

- `index.json` — manifest (`SummaIndex`): parts, question/article counts, source + license note.
- `prooemium.json` — the work-level prooemium (`Prooemium`).
- `part-I.json`, `part-I-II.json`, `part-II-II.json`, `part-III.json` — full content (`Part`).
- `search-index.json` — one `SearchRecord` per article; `text` is lowercased +
  diacritic-folded Latin for matching, `snippet` is a short original-case
  preview. For a precise snippet around a hit, load the article from the
  relevant `part-*.json` by `citation`. No search library is bundled — matching
  is Builder 2's job.
- `types.ts` — the interfaces for everything above (re-export from `src/` as needed).
- `VALIDATION_REPORT.md` — generated; current run: **PASS**, 0 errors.

### Known corpus facts (documented, not bugs)

- **No Supplementum** in this source: Proœmium + Prima/Prima Secundae/Secunda
  Secundae/Tertia Pars only. Tertia Pars ends at q. 90.
- **No Latin question titles** exist in the source — `Question.title` is always
  `null`. Show "QUAESTIO N"; the first article's `title` can be a secondary line.
- **~98.9%** of articles have a parsed `title` (the "utrum …" line, derived from
  the question prooemium enumeration). The rest are `null` (6 questions have no
  prooemium in the source; 1 unnumbered-article question has no list). Never fabricated.
- The source omits a few question numbers (I q. 72, II-II q. 143) and a few
  article numbers within questions — all listed in `VALIDATION_REPORT.md`.
- Two questions have a single **unnumbered** article (I q. 71, II-II q. 128):
  `Article.number` is `null` and its `citation` equals the question citation.
- The source Latin is plain ASCII (no ligatures/accents in the text itself).
