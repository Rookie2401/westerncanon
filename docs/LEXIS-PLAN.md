# Lexis — language help for the original-language edition

*Contract for the "linguistic help" build (2026-09-24). Every package imports the
types in `src/lexis/types.ts` and the tokenizer/keys in `src/lexis/tokenize.ts`
(mirrored for build scripts by `scripts/lexis/lib.mjs`). Nothing here applies to
the English edition: the whole feature is gated on `EDITION === 'original'`
(`src/library/edition.ts`) and on the user's "Language help" toggle.*

## 1. What the reader gets (original-language edition only)

- **Tap any word** in a Greek, Latin or Italian passage → a bottom-sheet word
  card, three levels deep (the Sefer/Slovo pattern):
  - **Level 1**: the word as printed · lemma · part of speech + morphology in
    plain English ("aorist indicative active, 3rd person singular") · short
    English gloss · status picker (new / seen / recognizing / known / mastered /
    ignored) · alternative readings as chips when the form is ambiguous.
  - **More**: every reading with its morphology; all short senses; the lemma's
    principal parts / inflection note where the dictionary gives one.
  - **Deeper**: the full dictionary article (LSJ or Middle Liddell for Greek,
    Lewis & Short for Latin, Wiktionary for Italian) rendered from trusted
    sanitised HTML; how many times the lemma occurs in this work; the reader's
    own history (lookups, encounters); a provenance line (analysis source ·
    dictionary · confidence).
- **Known-word tracking** per lemma (Dexie/IndexedDB), with automatic
  promotion after N unaided encounters (default 6, lookups count against it),
  bulk "mark the rest as known", export/import as JSON.
- **Highlighting** of words by status in the text (off / new only / all),
  matching the app's palette; the passage layout must not change when
  highlighting is off.
- **Coverage**: on the Work screen, "you know N % of the running words of this
  work" and per-language totals in the Vocabulary screen.
- **Settings › Language help**: master toggle (default ON in the original
  edition; absent from the English edition), highlight mode, auto-known
  threshold, "show morphology on the first level".
- **Honesty rules** (as everywhere in this app): an analysis is shown with its
  source and confidence; an unrecognised word is simply not tappable-with-a-card
  (it opens a card that says so and lets the reader mark it anyway); nothing is
  ever guessed silently; the build's coverage numbers are shipped and quoted in
  Settings.

## 2. Data layout

```
data/lexis/                                   (committed, generated by scripts/lexis/*)
  manifest.json                               LexisManifest
  works/<workId>.json                         WorkLexis - one per original-language work
  lex/<lang>/<shard>.json                     LexShard  - full entries by lexeme id
scripts/lexis/coverage.json                   build coverage (also copied into the manifest)
```
`scripts/copy-corpus.mjs` copies `data/lexis/` to `public/lexis/` for the
`original` (and `all`) edition only. `vite.config.ts` excludes `lexis/**` from
the precache and runtime-caches it (StaleWhileRevalidate) so a work's bundle is
fetched once, on first open, and kept.

Shard naming: `lex/<lang>/<shard>.json` where shard = the manifest's
`lex_shards[prefix]` for the longest prefix of the lexeme's *lemma key* (see
`shardPrefix()` in tokenize.ts); a shard is split when it would exceed ~250 KB.
The client never guesses a shard name: it resolves via the manifest.

## 3. Identifiers and keys (exact definitions live in `src/lexis/tokenize.ts`)

- **Form key** `looseKey(surface, lang)`: the lookup key of `WorkLexis.forms`.
  - `grc`: NFC → strip trailing elision marks (ʼ ’ ᾽ ') → lower-case (final ς
    kept). Accents and breathings are KEPT (they disambiguate).
  - `la`: NFC → macrons/breves stripped → lower-case → æ→ae, œ→oe, j→i; v kept.
  - `it`: NFC → lower-case → trailing apostrophe kept as part of an elided token
    ("l'", "dell'").
- **Fold key** `foldKey(surface, lang)`: `looseKey` plus, for `grc`, all
  diacritics removed and ς→σ; for `la`, v→u. Used only as a runtime fallback
  when the loose key misses (the bundle stores loose keys; the loader builds a
  fold map from them on load).
- **Lexeme id** `<lang>:<pos>:<lemma>`, e.g. `grc:noun:λόγος`, `la:verb:amo`,
  `it:noun:amore`; homographs of the same pos get `#2`, `#3`. The lemma is the
  dictionary headword spelling (Greek with accents; Latin without macrons,
  Lewis & Short spelling; Italian as Wiktionary).
- **Morph tags** (`Reading[1]`): space-separated, language-neutral, lower-case:
  pos first, then features. Vocabulary:
  - pos: `noun verb adj adv pron prep conj part num interj art name other`
  - case: `nom gen dat acc abl voc loc` · number: `sg pl du` · gender: `m f n`
  - person: `1 2 3` · tense: `pres impf fut aor perf plup futperf`
  - mood: `ind subj opt imp inf ptcp ger gdv sup` · voice: `act mid pass mp`
  - degree: `comp sup` · misc: `indecl encl`
  - Examples: `verb aor ind act 3 sg`, `noun acc pl f`, `adj nom sg m comp`,
    `verb ptcp perf mp nom sg n`, `prep`, `art nom sg m`.
  - `describeMorph(tags)` in the app turns this into prose; unknown tags are
    shown verbatim rather than dropped.
- **Confidence** (`Reading[2]`, 0–1): 1 = attested/gold (token-level
  lemmatised corpus or a dictionary form table hit that is the only reading);
  0.8 = analyser reading chosen by frequency among several; lower = guess.
  Readings are ordered best-first. Readings for one form are deduplicated by
  (lexeme id, morph).

## 4. Types — `src/lexis/types.ts` (authoritative; do not redefine elsewhere)

See the file. Summary: `LexisManifest`, `WorkLexis { workId, lang, tokens,
recognized, forms: Record<key, Reading[]>, lexemes: Record<id, CoreLexeme> }`,
`Reading = [lexemeId, morph, confidence?]`, `CoreLexeme { id, lemma, pos,
gloss, src? }`, `LexEntry extends CoreLexeme { senses?, html?, inflection?,
count? }`, `LexShard`, `LexisSettings`, `KnownWord`, `WordStatus`.

## 7. Acceptance

- `npm run typecheck`, `npm run lint`, `npm test` green; `npm run build` builds both editions; the English edition contains no `lexis/` directory and no lexis code paths reachable (tree-shaken or gated).
- Coverage per language, from the build, is quoted in Settings and in `scripts/lexis/coverage.json`; the orchestrator independently probes 30 random tokens per language against the bundles and the dictionaries.
- No text is ever altered: the tokenizer works on offsets into `Passage.text`, and the rendered text with help ON is character-identical to help OFF.
